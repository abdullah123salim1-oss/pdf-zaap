How to Convert JPG to PDF on Windows 11 & 10 (Free, Fast)

Published September 19, 2026 · 7 min read · By Abdullah Salim

Whether you need to compile photographic evidence for an insurance claim, submit scans of utility receipts for identity verification, or organize a design portfolio, sending loose JPG files is a recipe for disorder. Email attachments get scattered, image files lose their chronological sequence, and recipient web portals frequently reject raw graphic image extensions.

Converting your images into a single, structured PDF file organizes your presentation, standardizes paper dimensions, and ensures your paperwork looks identical across every device. Here are the two best ways to convert JPG images to PDF on Windows 11 and Windows 10 without paying for third-party software.

Quick Answer:

On Windows, you can convert JPGs natively by selecting images in File Explorer, right-clicking, selecting Print, and picking Microsoft Print to PDF. However, for full drag-and-drop page ordering, zero margin clipping, and multi-image combining, use PDFZaap JPG to PDF in your browser. It runs locally with zero uploads.

Method 2: Using Built-in "Microsoft Print to PDF" in Windows

Windows 10 and Windows 11 include a native virtual printer named Microsoft Print to PDF. You can use it directly from File Explorer without opening an internet browser.

Step 1: Locate Your JPGs in File Explorer

Open the folder containing your photos in Windows File Explorer.

Step 2: Select Your Images in Order

Hold Ctrl and click each photo you want to include. Important: Right-click on the first photo in your sequence—Windows uses the file you right-click on to determine which photo appears on page 1.

Step 3: Select "Print"

On Windows 10, click Print in the context menu. On Windows 11, click Show more options (or press Shift + F10) and then select Print.

Step 4: Configure the Virtual Printer

In the Print Pictures dialog window:

  • Set Printer to Microsoft Print to PDF.
  • Set Paper size to Letter or A4.
  • Set Quality to standard.
  • Crucial: Look at the checkbox at the bottom that reads "Fit picture to frame". If checked, Windows will crop the outer edges of your images. Uncheck it if you need the full picture visible!

Step 5: Click Print and Name Your PDF

Click Print in the lower-right corner. A Windows "Save Print Output As" dialog will appear. Choose a folder, type your desired filename, and click Save.

Troubleshooting Common Windows JPG to PDF Issues

1. The resulting PDF file size is over 30 MB

Smartphone cameras take pictures at 12–48 megapixels. Combining five or six phone photos into a PDF can easily create a 40 MB file that cannot be attached to an email. After converting, run the file through PDFZaap Compress PDF to reduce size under 2 MB while preserving sharpness.

2. Images appear sideways or inverted in the PDF

Sometimes Windows ignores EXIF orientation metadata tags embedded by iPhone or Android cameras. If a photo appears rotated, use the Rotate PDF Tool to turn individual pages 90° or 180° clockwise.

Frequently Asked Questions

Can Windows 11 convert JPG to PDF without installing extra software?

Yes. Windows 11 has a built-in virtual printer called 'Microsoft Print to PDF'. You can select image files in File Explorer, right-click, choose Print, and select Microsoft Print to PDF as the printer to save them as a document.

Why does Microsoft Print to PDF crop off the edges of my photos?

By default, the Windows Print Pictures dialog checks an option named 'Fit picture to frame', which crops photos to fill standard paper dimensions. Unchecking this box preserves image boundaries, but can leave wide awkward white margins. For exact edge-to-edge control and custom margins, use PDFZaap's JPG to PDF tool.
