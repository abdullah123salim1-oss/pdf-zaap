📤 Extract Pages from a PDF

Save selected pages as a new PDF

📥

Select your file

or drop file here

Processing document contents...

Files processed locally in your browser — nothing is uploaded to a server

Pull the pages you need out of a large document and save them as their own small PDF. Type the pages to keep — for example 1, 4-8 — and the tool copies exactly those pages, in order, into a new file. The source document is not modified, and the work happens entirely in your browser.

How to extract pages from a PDF

1

Select the PDF

Upload the document you want to pull pages from.

2

Enter the pages to keep

Use the Pages field: 1 for the first page, 4-8 for a range, or 1,3,5 for individual pages.

3

Click Extract Selected Pages

The listed pages are copied into a new document.

4

Download the new PDF

A compact file containing only your selections saves to your device.

Why use PDFZaap to build small documents from big ones, privately

The everyday workflow, without uploads. Extracting is how you turn a 300-page manual into the 4 pages a colleague needs, or a full contract bundle into the signature pages for a scan-and-email. Because it runs locally, the source file — often the most sensitive one — never leaves your device.

Lossless and reversible. Pages are copied whole: same text, same images, same quality. The original file stays untouched, so extraction is risk-free — if you picked the wrong range, run it again with the correct one. The one behavioral quirk: the new file's pages are numbered from 1, and bookmarks that referenced the unselected pages do not carry over.

Tips & common problems

  • Use extraction as the 'keep' half of a delete/keep split: extract what you want, and optionally delete those pages from the original later.
  • Combining extracted pages from several source documents? Add the results with Merge PDF.
  • For job applications where only two pages are allowed, extract exactly those pages and check the file size with Compress PDF if needed.
  • Step-by-step examples in How to split a PDF into single pages.
  • Extracting for a specific recipient? Name the output file after them or the purpose — extracted pages are easy to misfile.

When to use this vs. related tools

Use Extract Pages when you want to keep a selection as a new file. To discard pages, use Delete PDF Pages. The two tools are mirror images — same range syntax, opposite result. For reordering without removing, see Reorder Pages.A common pair: extract the pages you need, then Compress PDF the result if the recipient has a size limit.

Questions & Answers

Can I extract non-consecutive pages?▼

Yes — separate page numbers or ranges with commas: 1, 4, 7-9 keeps pages 1, 4, 7, 8 and 9.

Is the original file modified?▼

No. A new PDF is created; the source is unchanged.

What format is the output?▼

A standard PDF containing only the selected pages, in the order you listed them.

Does it work on password-protected PDFs?▼

Only after removing the restriction with Unlock PDF (password required).

What if I type a page number that does not exist?▼

Out-of-range numbers are ignored, so the extraction still succeeds with the valid pages you listed. Double-check your list to avoid silent gaps.
