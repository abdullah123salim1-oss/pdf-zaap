PDFs are terrible on small screens: fixed pages, tiny text, endless panning. This tool converts your PDF's text into a proper EPUB 3 e-book — reflowable, font-adjustable, with a table of contents — so it reads well on any e-reader or phone. The whole conversion, including the packaging step, happens locally in your browser.

Why use PDFZaap to build e-books without sending books to a server

Your library stays yours. Manuscripts, course books and internal reports do not need to pass through a conversion service. The text is read locally and the EPUB package is written locally; only the finished .epub is saved to your device.

Text-first, honestly stated. This converts the words — images and complex layout are not carried into the EPUB. For text-based books and reports that is a feature: the result reflows to your font size preference. For image-heavy books, expect a text-only companion rather than a full replica. Scanned books need OCR PDF first, since scans contain no real text.

Tips & common problems

  • Set your e-reader's font size after import — the whole point of reflowable text is reading comfort.
  • Use Split PDF to convert a single volume from a multi-book PDF.
  • Chapters follow PDF page boundaries, so long chapters are normal; split large books manually in your e-reader app.
  • For a plain text version instead, PDF to Text is a lighter alternative.
  • Import the EPUB into your e-reader before sharing it — a 30-second read-through catches ordering surprises early.

When to use this vs. related tools

Choose this when the destination is an e-reader. For documents you will edit, use PDF to Word; for a web page, PDF to HTML; for raw text, PDF to Text. Scanned sources should go through OCR PDF before conversion.For longer works, converting per volume (using Split PDF) gives you separate EPUB files that match the way people actually read them.

Questions & Answers

Will my e-reader accept the file?▼

The output is standard EPUB 3 with a navigation document — Apple Books, Kobo, Google Play Books and Calibre all accept it.

Are images included?▼

No. The conversion carries text only, which keeps the file small and the text selectable.

What about the table of contents?▼

Each PDF page becomes a chapter entry, so you get page-level navigation rather than detected headings.

Does it work on scanned books?▼

Not directly — run OCR PDF first to get real text, then convert the result.

What happens to headers and footers on each page?▼

They become part of the page's text flow, so running heads and page numbers appear as lines within each chapter. For a cleaner book, remove them from the source document first with Delete PDF Pages or a text pass.
