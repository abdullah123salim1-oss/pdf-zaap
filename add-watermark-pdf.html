💧 Add a Watermark to a PDF

Stamp text across every page of a PDF

Mark documents as DRAFT, CONFIDENTIAL, or with your name and date — on every page, in one click. Type the watermark text, adjust its opacity, and the tool stamps it across each page of the PDF. The processing is local in your browser, so even sensitive drafts never leave your device.

How to watermark a PDF

1

Select the PDF

Upload the document you want to mark.

2

Set the watermark text

The field defaults to CONFIDENTIAL — change it to DRAFT, SAMPLE, your name, a date, or any short label.

3

Adjust opacity

Lower values (around 0.2–0.4) keep the watermark subtle; higher values make it assertive.

4

Click Add Watermark

Every page is stamped and the finished file downloads.

Why use PDFZaap to protect drafts without uploading them

The classic use case is privacy. Watermarks usually appear on documents you are about to send to people who should not reuse them — proposals, specs, internal data. Stamping them in your browser means the document takes no trip to a third-party server at all.

What you get, precisely. A single text string is drawn on each page in a bold 50pt orange typeface, rotated 45°, at the opacity you choose, positioned in the upper-left area of the page. There is no image watermark support and no per-page variation — one label, whole document, which matches how watermarks are actually used. Because the stamp is drawn onto the pages, it cannot be removed by a reader; only the original unwatermarked file remains clean. Keep that original — a watermarked file is a finished state, not an editable one.

Tips & common problems

  • Short text works best (CONFIDENTIAL, DRAFT v2, YOUR NAME 2026) — the stamp is a fixed 50pt, so long labels can run off the page edge.
  • Opacity 0.3 is the usual balance: clearly visible, does not fight the content.
  • For 'do not print' workflows, a DRAFT watermark plus Protect PDF (password) is a strong pair.
  • Watermark before distributing — after a file circulates, you cannot pull versions back.
  • Version your watermarks (DRAFT v1, DRAFT v2) so leaked copies can be traced to a specific send.

When to use this vs. related tools

Use Add Watermark to label whole documents. For security beyond a visual mark, add a password with Protect PDF. For page references, Add Page Numbers is the companion tool. To make the stamped document fully static, follow up with Flatten PDF.If the document is headed to many recipients, pair the watermark with Protect PDF so the marked copy is also password-locked.

Questions & Answers

Can I use an image or logo as the watermark?▼

This tool applies text watermarks. For a logo stamp, you would need a tool with image-watermark support — we keep this one focused and honest.

Is the watermark permanent?▼

Yes — it is drawn onto each page, so readers cannot toggle it off. Only your original file stays unmarked.

Does it apply to every page?▼

Yes, the same text at the same opacity is stamped on all pages.

Why would I watermark a private document at all?▼

Watermarks discourage reuse and identify leaked copies — they are a deterrent and a trace, not an encryption. For true secrecy, use Protect PDF.

Can different pages have different watermarks?▼

No — one text, applied to every page. For per-page marks, watermark each extracted section separately and merge them back with Merge PDF.
